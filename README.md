# Expense Tracker

A simple command-line expense tracker written in Python.

## Features
- Enter multiple expenses with amount and category
- Type `q` to finish
- Shows a summary of all expenses and the total

## How to run
```bash
python3 tracker.py
```

## What I learned
Built as one of my first Python projects: while loops, lists, tuples, for loops and f-string formatting.
